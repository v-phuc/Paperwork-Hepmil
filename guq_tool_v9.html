Deploy Apps Script proxy (làm 1 lần duy nhất):
1. Mở script.google.com → New project
2. Xóa code cũ, dán code sau vào:
function doGet(e){
  var folderId = e.parameter.folderId;
  var folder = DriveApp.getFolderById(folderId);
  var files = folder.getFiles();
  var ids = [];
  while(files.hasNext()){
    var f = files.next();
    var mime = f.getMimeType();
    if(mime.indexOf('image')>-1){
      ids.push(f.getId());
    }
  }
  return ContentService
    .createTextOutput(JSON.stringify({ids:ids}))
    .setMimeType(ContentService.MimeType.JSON);
}
3. Deploy → New deployment → Web app → Execute as: Me → Who has access: Anyone → Deploy
4. Copy URL dạng https://script.google.com/macros/s/ABC.../exec → paste vào ô trên
✅ Chỉ cần làm 1 lần, dùng mãi mãi cho mọi folder Drive.
